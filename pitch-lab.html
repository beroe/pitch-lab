Settings

Notes shorter than “shortest note” (glancing open strings, bow noise) are dropped; lower it for fast passages. Lower the note-start threshold if the count beside “Note-start detection” goes up by less than one per note played; raise it if it counts extra starts on long notes. Bigger windows are steadier but slower to react. Raise the clarity threshold if bow noise or the room shows up as random notes; lower the noise gate in a quiet room, to about 10–15 dB above the level shown when you're not playing.

Timing test

Start the clicks and play one short note on each click, with headphones if you can. The average offset is the delay the game will subtract when scoring timing; the spread shows how steady detection is.

How to use. Tap Start microphone and allow mic access, then play single notes and watch whether the note name, cents and staff position are right. Try open strings, a slow scale, fast passages, repeated notes with separate bows, and vibrato. Demo plays a synthetic violin scale (with vibrato and slight random tuning) through the same detector, so you can see the app working without an instrument.

The microphone works only over https:// or on http://localhost.
